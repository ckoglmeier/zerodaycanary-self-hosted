Use the supplied file in the product; no external image URL or generation account is needed to display it. Preserve the master and alpha channel when deriving web sizes. Inspect any favicon derivative before shipping it.

Created October 22, 2026 using the **built-in imagegen tool**, generation mode, with `transparent_background: true`. No reference image was supplied and no CLI fallback was used. The result was copied into this project and visually inspected. The generated illustration includes subtle shading; keep UI color tokens defined in design.md rather than sampling the artwork.

## Final generation prompt

> Use case: logo-brand. Create a cute canary logo mark for Zero Day Canary, a professional web application that helps semi-technical administrators monitor software vulnerabilities. One friendly, alert little yellow canary, centered on a square transparent canvas, facing slightly right. A compact rounded body, confident upright stance, simple wing shape, small short beak, short tail, one dark eye with a tiny highlight. Warm canary yellow body approximately #F2CB4B, ochre wing, dark ink outline approximately #172B32. Cute and approachable but polished enough for a serious business product. Crisp flat vector-style geometry, smooth bold silhouette, very few shapes, consistent substantial outlines, recognizable at 32 pixels. Subject fills roughly 80 percent of canvas with clear space all around. No text, letters, wordmark, shield, lock, cage, helmet, accessories, gradients, glow, shadow, background scene, texture, or watermark. Genuinely transparent background; no checkerboard painted into artwork. Deliver a single finished logo, not a sheet of options.
