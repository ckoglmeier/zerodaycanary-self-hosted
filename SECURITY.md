# Security and maintenance

This project is unmaintained. No versions receive security patches, advisory updates or support from the original author. There is no hosted reporting or disclosure service.

Before operating a fork, review dependencies, authentication, authorization, network-fetch controls, credential storage and data retention. Maintain your own disclosure contact and response process. An empty report or catalog does not establish safety.

Do not post credentials, private reports or personal data in public issues. Fork maintainers are responsible for their own security updates and provider costs.
